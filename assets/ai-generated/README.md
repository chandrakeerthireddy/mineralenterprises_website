# Mineral Enterprises — AI ME Logo Assets

Master brand mark: green **M** (mineral veins) + gold **E**, spaced with E border/shade.

## Primary files

| File | Use |
|------|-----|
| `logo-me-final.svg` | **Saved master vector** (canonical — do not overwrite) |
| `logo-me-final-print.png` | Saved high-res print export (~1126×552) |
| `logo-me-final@2x.png` | Saved retina raster |
| `logo-me-final.png` | Saved header/footer raster |
| `logo-me-master.svg` | Editable working vector copy |
| `logo-me-print.png` | High-resolution raster for print/export |
| `logo-me@2x.png` | Retina header (~440px wide) |
| `logo-me.png` | Site header/footer (~218px wide) |

## Site usage

Header/footer reference: `logo-me.png?v=15` (PNG keeps AI vein detail).

For new materials, start from **`logo-me-master.svg`** and export at needed size.
